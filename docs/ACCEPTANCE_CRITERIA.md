# Acceptance criteria

## Global

- [ ] All four routes load directly and through navigation.
- [ ] No console errors during core journeys.
- [ ] No horizontal overflow at 360, 430, 768, 1024 and 1440 CSS pixels.
- [ ] No text overlap, clipped controls or unreadably small type.
- [ ] Keyboard focus is visible and every action is reachable.
- [ ] Reduced-motion mode removes zoom, scatter, continuous travel and 3D rotation without losing content.
- [ ] `WHAT_NOT.md` has been checked item by item.
- [ ] No secret or private identifier exists in the repository or browser bundle.
- [ ] Production build, lint, type-check and tests pass.

## Home

- [ ] Supplied greeting animation loads and has a fallback.
- [ ] Greeting does not trap repeat visitors or reduced-motion users.
- [ ] Football character crosses both directions with no obvious reset.
- [ ] `@theprathambatra` moves as an integrated part of the hero.
- [ ] Ball kick transitions into work experience.
- [ ] Work elements converge into a briefcase that visibly closes.
- [ ] Education facts match structured content and hide unknown dates.
- [ ] Education transforms into music postcards.
- [ ] Featured Spotify content has an Open in Spotify action.

## Work Orbit

- [ ] All 18 approved sites appear.
- [ ] Every URL is correct and opens safely in a new tab.
- [ ] Desktop orbital interaction works with pointer and keyboard alternative.
- [ ] Mobile interaction works without hover.
- [ ] Live websites are not all mounted as iframes.
- [ ] Swawlambi services, logo, map and office address are present.
- [ ] Unverified Swawlambi numbers include the exact disclosure.
- [ ] No unsupported result from the BYOB reference is published.

## Music Vault

- [ ] Data layer supports at least 5,000 records with cursor pagination or equivalent.
- [ ] Only the visible portion of the catalog is rendered.
- [ ] Search and filtering remain responsive.
- [ ] A bounded number of Spotify embeds are active.
- [ ] The route is still useful when Spotify credentials are missing.
- [ ] Copy does not claim universal free or full playback.

## Social and GitHub

- [ ] Fallbacks are labelled honestly when an integration is not live.
- [ ] Instagram and LinkedIn are not scraped.
- [ ] No contribution, follower, post or engagement number is fabricated.

## Contact

- [ ] Supplied photo is displayed with appropriate cropping and alt text.
- [ ] Email and WhatsApp actions work.
- [ ] Instagram, LinkedIn, GitHub and Spotify links work.
- [ ] Swawlambi address and map work.
- [ ] Booking shows an embed only when a valid public URL exists.

## Performance

- [ ] Heavy 3D and media code is lazy-loaded.
- [ ] Continuous animation pauses offscreen or when the document is hidden.
- [ ] Images have sizes and efficient formats.
- [ ] No 5,000-item DOM render.
- [ ] ScrollTrigger and requestAnimationFrame listeners are cleaned up.
